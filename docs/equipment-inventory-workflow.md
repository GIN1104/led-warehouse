# Workflow оборудования без сканера

Страница: [`/stock`](https://GIN1104.github.io/led-warehouse/stock/) (нав «Оборудование»).

## Статусы qty-строки

| Статус | Смысл |
|--------|--------|
| `available` | Доступно на складе |
| `reserved` | Забронировано (заказ / импорт mapper) |
| `checked_out` | Вышло со склада (вручную; позже — рамка) |
| `needs_repair` | Нуждается в ремонте |
| `in_repair` | В ремонте |

Переходы пишутся в `equipment_status_history`.

## Права: просмотр vs редактирование

- На [`/people`](https://GIN1104.github.io/led-warehouse/people/) блок **«Редактирование склада»**: у каждой роли флажок «может редактировать склад».
- **Администратор** — включён по умолчанию; остальные по настройке (seed также включает роль **Склад**, чтобы не ломать текущий UX).
- Сессия без права → **режим просмотра** на `/stock`: без inline qty, без «Изменить» группу, без add/delete/↑↓ и без CRUD комплектов.

## Flow для склада

1. **Сводка «Всё оборудование»**: группы → подгруппы (SKU) + **вложенные подстроки комплектов**.
   - **Desktop (md+):** sticky-шапка колонок к **viewport** (под навбаром `top-14`), не внутри карточки: без `overflow`/`max-height` обёртки. Колонки: порядок / код / название / всего / на складе / в работе / в ремонте / заказы. Ряды в одну линию (`align-middle`); inline qty без прыжков.
   - **Mobile (~375px):** карточки групп/SKU (qty сеткой 2×2), без page-wide horizontal overflow. Сайдбар — overlay-drawer (по умолчанию закрыт), не сжимает контент. Nested kits и view-only сохраняются.
   - Порядок только по `sort_order`; scroll/focus страницы сохраняются после refresh.
   - **Добавить в группу** / **Удалить** элемент (подтверждение; если SKU в заказах — блокировка с предупреждением; иначе каскад qty-строк).
   - Пустую группу можно удалить.
   - **Порядок** ↑↓; **имена/qty** inline; смена группы — кнопка **«Изменить»** у названия (не отдельная всегда видимая строка); «Кабинет…» → «Кабинеты».
   - Под SKU комплекта (например **Laptop**, код `LAPTOP`, не LEPTOP): nested №1/2/3 → checklist `HDMI×2` прямо в этой таблице. Комплект можно повесить на **любую** группу (кабинеты, контроллеры, …).
   - **Кабинеты:** под SKU с размером в имени — **м² · кубики · кейсы** (500×500 → 8/кейс; 1000×500 → 6/кейс, `ceil`).
2. **Группа комплекта** (блок ниже): выбрать существующую группу оборудования или создать новую → подтип → синхрон в сводку (`family_id` / `sku_id`). Экземпляры/checklist — во вложенных строках сводки. Migrate чинит LEPTOP→Laptop в **name и code** SKU, kits и `product_families`.
3. **Группы и варианты**: создать группу, добавить вариант, ↑↓.
4. **Добавить** позицию вручную → `available`.
5. **Импорт Excel/CSV** mapper → `reserved`. Drive: **ДД-ММ-ГГГГ**. См. [excel-sku-hierarchy.md](excel-sku-hierarchy.md).
6. **Вышло со склада**; **Приём / возврат** (частичный qty + флаг повреждения → `needs_repair`) / частичный ремонт.
7. Фильтр/поиск в детальной таблице строк.
8. Заказ: kit-аксессуары авто в чеклист на карточке заказа (собрано / снять). **PDF packing не делаем.** См. [checkin-kits-cabinets.md](checkin-kits-cabinets.md).

Импорт заказа на `/orders` зеркалит qty как `reserved`.
