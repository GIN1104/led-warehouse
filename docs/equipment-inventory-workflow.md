# Workflow оборудования без сканера

Страница: [`/stock`](https://GIN1104.github.io/led-warehouse/stock/) (нав «Оборудование»).

## Статусы qty-строки

| Статус | Смысл |
|--------|--------|
| `available` | Доступно на складе |
| `reserved` | Забронировано (заказ / импорт mapper) |
| `checked_out` | Вышло со склада (вручную; позже — рамка) |
| `needs_repair` | Нуждается в ремонте |
| `in_repair` | В ремонте |

Переходы пишутся в `equipment_status_history`.

## Flow для склада

1. **Сводка «Всё оборудование»** вверху `/stock`: группы → подгруппы (SKU). Qty правите в таблице: **всего / на складе / в работе / в ремонте**. Модель: `всего = склад + в работе + ремонт`. В работе — ссылки на заказ.
2. **Группы и варианты**: создать группу («Телевизор»), добавить подгруппы/SKU (`TV 32"`, `40"`…). Сортировка ↑↓.
3. **Добавить** позицию вручную → статус `available`.
4. **Импорт Excel/CSV** из mapper → строки `reserved`. Достаточно **название + количество**. Подробности: [excel-sku-hierarchy.md](excel-sku-hierarchy.md). Имена Drive: **ДД-ММ-ГГГГ**.
5. **Вышло со склада** → `checked_out`.
6. **Нужен ремонт** / **В ремонте** — можно указать **часть qty** (например 2 из 80); остаток остаётся в текущем статусе.
7. Сортировка и фильтр по статусу / поиску.

Импорт заказа на `/orders` зеркалит qty-строки как `reserved`.
