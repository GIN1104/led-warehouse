# Workflow оборудования без сканера

Страница: [`/stock`](https://GIN1104.github.io/led-warehouse/stock/) (нав «Оборудование»).

## Статусы qty-строки

| Статус | Смысл |
|--------|--------|
| `available` | Доступно на складе |
| `reserved` | Забронировано (заказ / импорт mapper) |
| `checked_out` | Вышло со склада (вручную; позже — рамка) |
| `needs_repair` | Нуждается в ремонте |
| `in_repair` | В ремонте |

Переходы пишутся в `equipment_status_history`.

## Flow для склада

1. **Сводка «Всё оборудование»**: группы → подгруппы (SKU).
   - **Добавить в группу** / **Удалить** элемент (подтверждение; если SKU в заказах — блокировка с предупреждением; иначе каскад qty-строк).
   - Пустую группу можно удалить.
   - **Порядок** ↑↓; **имена/qty** inline; **перенос** select’ом; «Кабинет…» → «Кабинеты».
2. **Группы и варианты**: создать группу, добавить вариант, ↑↓.
3. **Добавить** позицию вручную → `available`.
4. **Импорт Excel/CSV** mapper → `reserved`. Drive: **ДД-ММ-ГГГГ**. См. [excel-sku-hierarchy.md](excel-sku-hierarchy.md).
5. **Вышло со склада** / **частичный ремонт**.
6. Фильтр/поиск в детальной таблице строк.

Импорт заказа на `/orders` зеркалит qty как `reserved`.
