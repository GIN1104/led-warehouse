# Workflow оборудования без сканера

Страница: [`/stock`](https://GIN1104.github.io/led-warehouse/stock/) (нав «Оборудование»).

## Статусы qty-строки

| Статус | Смысл |
|--------|--------|
| `available` | Доступно на складе |
| `reserved` | Забронировано (заказ / импорт mapper) |
| `checked_out` | Вышло со склада (вручную; позже — рамка) |
| `needs_repair` | Нуждается в ремонте |
| `in_repair` | В ремонте |

Переходы пишутся в `equipment_status_history`.

## Flow для склада

1. **Сводка «Всё оборудование»**: группы → подгруппы (SKU).
   - **Порядок** ↑↓ (`sort_order`, IndexedDB/SQLite).
   - **Редактирование** в таблице: имя группы, имя SKU, qty (всего / склад / в работе / ремонт; `всего = сумма`), перенос SKU в другую группу (select).
   - **Умный дефолт группы**: «Кабинет LED P3.9…» → группа «Кабинеты», не отдельная верхняя группа.
2. **Группы и варианты**: создать группу, добавить вариант в выбранную группу, ↑↓.
3. **Добавить** позицию вручную → `available`.
4. **Импорт Excel/CSV** mapper → `reserved`. Drive имена: **ДД-ММ-ГГГГ**. См. [excel-sku-hierarchy.md](excel-sku-hierarchy.md).
5. **Вышло со склада** → `checked_out`.
6. **Частичный ремонт** — qty часть строки; остаток остаётся.
7. Фильтр/поиск в детальной таблице строк.

Импорт заказа на `/orders` зеркалит qty как `reserved`.
