# Локации: склад и объекты на карте

**Страница:** [`/locations`](https://GIN1104.github.io/led-warehouse/locations/)

## Модель

Один **главный склад** (`kind=warehouse`) и **объекты работ** (`kind=site`) — площадки/venues, куда уезжает оборудование. Зоны и ячейки (`zone` / `bin`) остаются для раскладки внутри склада.

Поля геолокации (без GIS):

| Поле | Назначение |
|------|------------|
| `address` | Адрес текстом |
| `lat` / `lng` | Координаты (оба вместе или оба пустые) |

## «Открыть карту»

Из адреса или координат строятся внешние ссылки:

- Google Maps
- Apple Maps (предпочтительно на Apple-устройствах)
- OpenStreetMap

Встроенной карты нет — только deep-link.

## CRUD

Право `location.write` (роль склада): создать / изменить / удалить. Удаление блокируется, если есть остаток, движения, перемещения, оборудование или дочерние локации.
