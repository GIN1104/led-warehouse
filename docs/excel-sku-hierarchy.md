# Excel → SKU без кодов и иерархия групп

Страница: [`/stock`](https://GIN1104.github.io/led-warehouse/stock/).

## Зачем

Excel из mapper часто содержит только **название + количество**, без артикула. Система сама присваивает стабильный `code` и раскладывает позиции по группам (например «Телевизор» → `TV 32"`, `40"`, `50"`).

## Колонки Excel / CSV

Нужны **qty** и хотя бы одно из **name** или **code**. Заголовки сопоставляются **без учёта регистра**, с trim и нормализацией пробелов/дефисов (`Кол-во` = `кол во` = `QTY`).

| Поле | Примеры заголовков (RU / EN / HE) | Обязательно |
|------|-----------------------------------|-------------|
| **name** | `название`, `наименование`, `оборудование`, `Оборудование`, `name`, `item`, `description`, `equipment`, `ציוד`, `שם`, `פריט`, `תיאור` | да*, если нет code |
| **qty** | `количество`, `кол-во`, `qty`, `quantity`, `QTY`, `כמות`, `כמויות`, `כמות יח׳` | да |
| **code** | `code`, `sku`, `артикул`, `код`, `קוד`, `מק״ט` | да*, если нет name |
| **notes** | `notes`, `заметка`, `תופסות` | нет |
| **category** | `категория`, `группа`, `category`, `family`, `group`, `קטגוריה` | нет |
| **customer** | `заказчик`, `customer`, `לקוח` | нет |
| **external_id** | `external_id`, `order_id`, `номер` | нет |

\* Нужны **qty** и хотя бы одно из **name** или **code**.

## Ожидаемый layout mapper Excel

Типичный файл из mapper (см. [`examples/equipment-list-Trask-Splesh.xlsx`](../examples/equipment-list-Trask-Splesh.xlsx)):

| Строка | Содержимое |
|--------|------------|
| A1 | `תאריך: DD.MM.YYYY` — мета (дата события → `startDate`) |
| A3 | `שם האירוע: …` — мета (название → `customerName`) |
| A5:D5 | **Заголовки:** `ציוד` \| `Оборудование` \| `כמויות` \| `תופסות` |
| 6… | Данные: A = имя HE, B = имя RU (display), C = количество, D = заметки |
| низ | `מיקום:`, `שעות:`, `איש קשר:`, `רכב:`, `סוג:` — мета, пропускаются |

Правила разбора:

1. **Мета-строки** (`תאריך:`, `Date:`, `שם האירוע:`, `מיקום:`, …) и пустые строки пропускаются; заголовок ищется в первых ~30 строках.
2. **name** = колонка B (`Оборудование`), если заполнена; иначе A (`ציוד`) с glossary HE→RU.
3. **qty** из C: чистое число; `+` → 1; пусто → 1; из длинного текста берётся **первое целое**, остаток C+D → `note` строки.
4. Без заголовков: 2 колонки `name,qty` или пары glossary-имя + qty.

### Ошибка сопоставления

Если столбцы не распознаны, сообщение показывает:

1. какие заголовки **увидели** в файле;
2. какие **алиасы принимаются** для name / qty / code / category;
3. **preview первых 5 строк** файла.

Пример CSV: [`examples/mapper-equipment-name-qty.csv`](../examples/mapper-equipment-name-qty.csv).

Кавычки дюймов в CSV экранируйте по стандарту: `"TV 32"""`.

## Иврит → русский (glossary)

Mapper-файлы часто с названиями на иврите. Словарь: [equipment-he-ru-glossary.md](equipment-he-ru-glossary.md) (`src/lib/domain/he-ru-glossary.ts`).

- Точное совпадение HE-ключа → русское display name (например `מסך` → `Экран`).
- `name_key` и авто-`code` строятся от канонического русского → один HE = один SKU; повторный импорт того же RU не дублирует.

## Как генерируется code

1. **Нормализация имени** (`name_key`): после glossary — trim, нижний регистр, схлопывание пробелов, унификация кавычек.
2. Один `name_key` → один SKU (повторный импорт того же названия не создаёт дубль).
3. **Человекочитаемый code**, где удаётся:
   - `TV 32"` / `Телевизор 40"` → `TV-32`, `TV-40`
   - кабинет P2.5 → `CAB-P25`
   - иначе slug (транслит) или `SKU-<hash>`
4. При коллизии с другим именем — суффикс из короткого хеша `name_key`.

## Модель

- `product_families` — группа (категория)
- `skus.family_id`, `skus.name_key`, `skus.sort_order` — привязка, стабильный ключ, порядок в группе

## Иерархия в UI

На `/stock` блок **«Группы и варианты»**: создать группу, добавить вариант (code опционален), сортировка ↑↓.

Импорт с колонкой категории сам создаёт группу и кладёт SKU внутрь. Статус позиций после импорта — `reserved`.

## Имена файлов на Google Drive

При сохранении/экспорте Excel в папку Drive имя начинается с **ДД-ММ-ГГГГ**: `18-10-2026.xlsx` или `18-10-2026 Имя события.xlsx`. Layout листа mapper не меняется. Код: `src/lib/google/drive-filename.ts`.
