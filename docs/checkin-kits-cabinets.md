# Check-in, kit в заказе, кейсы кабинетов

## Check-in / возврат (M3)

На `/stock` у строк со статусом **Вышло со склада** — кнопка **«Приём / возврат»**:

- qty (частичный ок);
- флаг **«Повреждено → ремонт»** → `needs_repair`, иначе → `available`;
- история пишет `check-in` / `check-in damaged`.

PDF packing **не** делаем (список меняется до выезда).

## Kit-аксессуары в заказе (M2)

При `createOrder`, если у SKU есть kit subtype, в таблицу `order_accessories` копируется шаблон из первого unit (qty × число в строке).

На карточке заказа (`/orders/view`):

- чеклист «есть» (`assembled`);
- **Снять** позицию (`cancelled`) если чего-то не хватает;
- можно вернуть в список.

## Кабинеты: м² / кубики / кейсы

Правила (см. preferences):

| Форм-фактор | В кейсе | м² кубика |
|-------------|---------|-----------|
| **500×500** | **8** | 0.25 |
| **1000×500** | **6** | 0.5 |

Кейсы = `ceil(кубики / perCase)`. В сводке `/stock` под SKU с размером в имени.

Код: `src/lib/domain/cabinet-pack.ts`. Seed: `CAB-P28-10` (1000×500).
